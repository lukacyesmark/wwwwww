Časté otázky

Potřebuji osobní web, když mám LinkedIn?

LinkedIn vám nepatří a nepřivede klienty z Googlu. Osobní web je vaše vizitka, kterou máte pod kontrolou.

Kolik stránek má osobní web?

Obvykle 3–8. Často stačí jednostránkový web s kvalitním portfoliem.
