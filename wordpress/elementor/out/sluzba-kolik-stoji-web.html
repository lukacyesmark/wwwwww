Kolik stojí web: 8 faktorů, které rozhodují

Dva weby se stejným počtem stránek mohou stát velmi rozdílně. Tady je proč.

01

Počet stránek

Jednostránkový web je levnější než web s desítkami podstránek služeb a referencí.

02

Texty

Dodáte texty sami, nebo je máme napsat? Kvalitní obsah je práce, ale vyplatí se i pro SEO.

03

Fotky a grafika

Vlastní fotky, fotobanka, nebo focení na místě? Logo a vizuální styl jsou samostatná položka.

04

Funkce

Rezervace, kalkulačky, filtry, napojení na externí systémy – každá funkce přidá práci.

05

Jazykové verze

Němčina nebo polština pro turisty znamená další texty i technické nastavení.

06

E-shop

Produkty, platby, doprava a obchodní podmínky – e-shop je samostatná kategorie projektu.

07

Design na míru

Úprava osvědčeného rozložení je levnější než úplně originální grafika.

08

Správa po spuštění

Aktualizace, zálohy a úpravy můžete řešit sami, nebo je předat nám.

Kolik stojí provoz webu a jde to levně?

K ceně tvorby připočítejte provoz. Doména .cz stojí řádově stovky korun ročně, běžný hosting pro WordPress stovky až nižší tisíce korun ročně. Pokud chcete, aby se o aktualizace a zálohy staral někdo jiný, přidejte správu webu.

Tvorba webových stránek levně – kde ušetřit

Ušetřit se dá rozumně: připravte si podklady, dodejte vlastní fotky, začněte s menším rozsahem a web rozšiřujte postupně. Neušetříte ale na obsahu a struktuře – web bez promyšlených textů nepřivede zákazníky, ať stál kolik chtěl.

Proč nevolit nejlevnější nabídku

Velmi levný web často znamená šablonu bez SEO, bez možnosti úprav, nebo web, ke kterému nemáte přístup. Při porovnání nabídek se ptejte, kdo bude web vlastnit, jak se upravuje a co se stane po spuštění.

Kolik stojí web, který vydělává?

Lepší otázka než „kolik stojí web“ je, kolik vám web přinese. Pokud díky němu získáte pár zakázek ročně navíc, vrátí se investice rychle. Proto navrhujeme každý web s jasnou cestou k poptávce.
